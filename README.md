# 드레스룸 스토어 (배치 플래너 쇼핑몰)

방 치수를 넣고 모듈을 배치한 뒤, 그 구성 그대로 장바구니에 담아 토스페이먼츠로 결제하는 쇼핑몰입니다.
Vercel에 그대로 올리면 동작하며, 별도 빌드 과정이나 외부 패키지가 없습니다.

## 페이지

| 주소 | 내용 |
|---|---|
| `/` | 메인 (추천 세트, 모듈 구성, 주문 방법) |
| `/planner` | 배치 플래너 (장바구니 담기, 카카오톡 상담 버튼) |
| `/cart` | 장바구니 (색상·수량 변경) |
| `/checkout` | 주문서 + 토스페이먼츠 결제위젯 |
| `/success`, `/fail` | 결제 결과 (서버에서 금액 확인 후 결제 승인) |
| `/order` | 비회원 주문 조회 (주문번호 + 휴대폰 번호) |
| `/admin` | 관리자: 주문 관리(상태, 송장, 메모, 결제 취소·환불), 단가·배송비 |
| `/planner#admin` | 관리자: 세트 만들기·고치기, 단가 변경 |
| `/policy` | 이용약관, 개인정보처리방침, 교환·환불 안내 (기본 틀) |

## 배포 순서

1. **GitHub에 올리기**: 이 폴더 전체를 새 저장소로 올립니다. (`.env.example`, `.gitignore` 같은 숨김 파일도 함께)
2. **Vercel 프로젝트 만들기**: Vercel에서 저장소를 Import 합니다. Framework Preset은 `Other`, 빌드 설정은 비워 둡니다.
3. **저장소 연결**: Vercel 프로젝트 → Storage(또는 Marketplace) → **Upstash Redis** 추가 → 이 프로젝트에 연결합니다.
   `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경 변수가 자동으로 들어갑니다. 주문과 단가·세트 설정이 여기에 저장돼요.
4. **환경 변수 추가**: Settings → Environment Variables
   - `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`: 토스페이먼츠 개발자센터 → API 키 → **결제위젯 연동 키**
   - `ADMIN_PASSWORD`: 관리자 비밀번호 (8자 이상, 길고 추측하기 어렵게)
5. **다시 배포(Redeploy)** 하면 끝입니다.

처음에는 `.env.example`에 있는 토스페이먼츠 문서용 테스트 키로 결제 흐름을 시험할 수 있어요. 테스트 키로는 실제 돈이 나가지 않아요.

## 판매 시작 전 꼭 할 일

- `js/shop-config.js`에 상호, 대표자, 사업자등록번호, 통신판매업 신고번호, 주소, 연락처, 개인정보 보호책임자를 채웁니다. 전자상거래법상 표시 의무가 있고, 토스페이먼츠 심사에도 필요해요. 비어 있으면 화면 하단에 빨간 "입력 필요"가 보여요.
- `policy.html`의 [대괄호] 부분을 채우고 전문가 검토를 받습니다.
- 토스페이먼츠와 전자결제 계약 후 **라이브 키**로 환경 변수를 바꾸고 다시 배포합니다.
- 카카오톡 채널이 있으면 `js/shop-config.js`의 `kakaoChannelUrl`에 1:1 채팅 주소를 넣습니다. 플래너에 "카카오톡으로 상담하기" 버튼이 생겨요.

## 상품·가격 관리

- **단가·배송비**: `/admin` → 단가·배송비 탭에서 저장하면 모든 고객에게 바로 적용됩니다.
- **세트**: `/planner#admin` → 관리자 설정 → 세트 설정. 배치를 만들고 "현재 배치로 새 세트"를 누른 뒤 저장합니다.
- **모듈 종류·판매 폭·색상 추가**: `js/catalog.js` 한 파일만 고치면 화면과 서버(가격 검증)에 함께 반영됩니다.

## 결제 안전장치

- 결제 금액은 브라우저가 아니라 **서버가 저장된 단가로 다시 계산**합니다.
- 결제 승인 전에 토스에서 돌아온 금액과 서버의 주문 금액이 다르면 승인하지 않습니다.
- 같은 결제를 두 번 승인하지 않도록 처리돼 있습니다(새로고침해도 안전).
- 관리자 기능은 `ADMIN_PASSWORD`로만 접근됩니다. 입력한 비밀번호는 브라우저 탭을 닫으면 지워집니다.

## 파일 구조

```
api/                서버 함수 (Vercel Serverless Functions)
  config.js         결제 키·저장소 연결 상태
  settings.js       단가·세트·배송비 조회/저장
  orders.js         주문 생성 (금액은 서버에서 계산)
  confirm.js        토스페이먼츠 결제 승인
  lookup.js         비회원 주문 조회
  admin/orders.js   관리자 주문 목록·상태 변경·결제 취소
  _lib/             공용 코드 (Redis, 검증, 주문 계산)
js/catalog.js       상품 카탈로그 (화면·서버 공용 원본)
js/common.js        장바구니, 금액 계산, 정면도 그림, 머리글·바닥글
js/shop-config.js   쇼핑몰·사업자 정보
css/shop.css        공통 스타일
*.html              각 페이지
```

## 아직 없는 기능 (필요하면 추가)

회원 가입·로그인, 쿠폰·할인, 재고 관리, 알림톡·문자 발송, 가상계좌 입금 웹훅, 관리자 로그인 실패 횟수 제한.
